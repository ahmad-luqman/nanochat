# Course Diagrams

This directory contains visual diagrams to support the LLM learning course.

## Available Diagrams

1. **architecture.md** - GPT model architecture
2. **attention.md** - Attention mechanism visualization
3. **data_flow.md** - Data flow through the system
4. **training_pipeline.md** - Training stages and pipeline

## Format

All diagrams use **Mermaid** format for easy rendering in markdown viewers and GitHub.

## Usage

Include diagrams in course materials by referencing them:
```markdown
See [Architecture Diagram](diagrams/architecture.md) for visual explanation.
```
